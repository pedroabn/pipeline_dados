# OBJETIVOS
### Objetivo Geral
Construir e documentar uma pipeline de dados para marketing analytics e um dashboard para visualização de dados.

### Objetivos Específicos
Desenvolver um fluxo estruturado de extração, tratamento e carregamento de dados
Implementar rotinas de aplicação de processos automatizados
Aplicar técnicas de análise estatística e de probabilidade na segmentação das campanhas
Construir um modelo de random forest baseado em comportamento de consumo
Construção de um framework forte e com escalabilidade
